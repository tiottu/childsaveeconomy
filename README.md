# 우리아이통장

아이들의 용돈(현금)과 주식투자를 함께 관리하는 핸드폰용 웹앱.

**주소**: https://tiottu.github.io/childsaveeconomy/

## 무엇을 하나

- **통장** — 용돈 입금과 지출 기록, 월별 "모은 돈" 추이
- **투자** — 국내·미국 주식을 실제 시세로 기록 (네이버 증권)
- **칭찬도장** — 아이가 잘한 일을 신청하고 부모가 도장을 찍는다. 모으면 보상
- **목표** — 저축 목표와 진행률

## 누가 무엇을 보나

| | 보이는 것 | 할 수 있는 것 |
| --- | --- | --- |
| 엄마 · 아빠 | 아이들 전체 | 전부 (권한 동일) |
| 아이 | 자기 것만 | 조회 + 도장·목표 신청 |

엄마와 아빠는 **권한이 같다.** 이름표는 서로 다른 핸드폰을 구분하기 위한 것이다.

아이 화면은 다른 아이의 이름조차 보이지 않는다. 화면에서 숨기는 게 아니라
Postgres 의 RLS 가 서버에서 막는다.

## 어떻게 붙나

- **부모**: 이메일 + PIN 6자리. 이메일은 확인하지 않는다 — 어느 집인지 가리키는
  이름표일 뿐이고 진짜 비밀은 PIN 이다. 배우자 핸드폰도 같은 이메일과 PIN 을 쓴다
- **아이**: 부모가 알려준 **가족 코드**. 이메일이 필요 없고, 익명 계정이라
  RLS 가 쓰기를 완전히 막는다

## 만든 것

- React 18 + TypeScript + Vite
- Supabase (Postgres · RLS · Realtime · Edge Functions)
- GitHub Actions 가 빌드해서 GitHub Pages 로 배포한다

## 고치는 방법

바뀐 파일을 GitHub 웹 편집기에서 덮어쓰고 커밋하면 자동으로 다시 배포된다.

```
https://github.com/tiottu/childsaveeconomy/edit/main/<파일경로>
```

빌드 설정 두 가지만 조심한다.

- `vite.config.ts` 의 `base` 는 저장소 이름과 같아야 한다. 틀리면 화면이 하얗게만 뜬다
- Supabase 주소와 키는 `.env.production` 에 있다. 워크플로에서 환경변수로 덮어쓰면
  안 된다 — 환경변수가 `.env` 파일보다 우선해서 빈 값이 이긴다
